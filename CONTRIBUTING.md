# Contributing to Junimod

Build from the repository root with `swift build`. Changes should keep existing Stardrop settings and profile formats compatible.

For bug reports, include the app and macOS versions, steps to reproduce, and the Junimod log. Open the log folder from the sidebar, or find it at `~/Library/Application Support/Stardrop/Data/Logs/junimod.log`. Review logs for personal information before sharing them. For game launch issues, also include a [SMAPI log](https://smapi.io/log).

Report problems through the [Nexus posts page](https://www.nexusmods.com/stardewvalley/mods/53356?tab=posts) or GitHub issues when enabled.
